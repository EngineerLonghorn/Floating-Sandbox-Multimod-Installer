Welcome to the Floating Sandbox Multimod Installer, this installer is designed to package all the mods in the Floating Sandbox: Designer's Studio Discord Server into one simple installer for ease of use.

If you have not used this installer before or are having issues, it's recommended you read this first.

After clicking "Next", you will be shown an installation path that will dictate where the mod files are meant to go. You should only change this if you changed the installation path of Floating Sandbox itself when you installed Floating Sandbox. If you have changed the installation path, make sure to set it to the 'Floating Sandbox' folder where your floatingsandbox.exe application file is.

After choosing your installation path, you will be shown a list of components, or mods, to install. The top, primary checkboxes dictate whether or not you are going to make any changes to that aspect, be it materials, smoke, or tools. If enabled, you may either install a mod or install the vanilla files - in the event you either don't want a mod or want to uninstall a mod, choose the vanilla files.

!! NEW !!
Extra Materials v4.8 has removed several hundreds of seldom-used materials to improve stability with Floating Sandbox 1.21. If you find any of your ships do not load, only then should you install Extra Materials Legacy v4.8 (which retains those removed materials), and I strongly recommend only using the Legacy version for migrating your ships over to non-Legacy-exclusive materials. Continue to the bottom for a guide on migrating your ships.

After choosing what mods to install, you will be prompted with a confirmation page, then the Multimod Installer will start, well, installing the mods, and you should be good to go after that.

If you have any issues or problems, make a bug report forum post in the Floating Sandbox Designer's Studio Discord server, or message Longhorn via 'looonghorn' on Discord.

Enjoy!

!! GUIDE REGARDING MIGRATION !!
I'd recommend exporting your ship structure as a PNG, loading the PNG in Floating Sandbox with Extra Materials v4.8 non-Legacy, then screenshot any missing materials (which will be in the form of holes in the ship), then return to Extra Materials v4.8 Legacy, and go to where those holes (which are the removed materials) correspond to, and patch them with non-Legacy-exclusive materials.  
As a tiny side-note to this: if you've used the Self-Powered Bell 2 in one of your ships prior to Floating Sandbox 1.21 and Extra Materials v4.7, you will need to go back to Floating Sandbox 1.20 and Extra Materials v4.6 to remove it, or directly message Longhorn (`looonghorn`) on Discord and I will fix it when I have the time to.

!! KNOWN BUGS FOR EXTRA MATERIALS !!
- For Gasoline to work properly, please avoid contact with water, and have all your gasoline be at least 2 pixels in both width and height.
- Uranium 235 and Plutonium 239 can crash Floating Sandbox or otherwise make it unstable when there are multiple other explosives onboard a ship. 
- Opening the material palette in the shipbuilder can sometimes temporarily freeze Floating Sandbox. If you experience this, you may have better luck closing other programs you have open.
- The electrical panel editor in the shipbuilder is a lot more tempermental with large amounts of electrical materials when Extra Materials is installed. There is currently no solution to this besides switching back to the vanilla materials.
- Floating Sandbox 1.20 and Extra Materials v4.7 (possibly v4.6 as well) are known to be temperamental with each other, and will result in GUI glitches (missing buttons or menus) and crashes. Please update to Extra Materials v4.8.
