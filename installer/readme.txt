Welcome to the Floating Sandbox Multimod Installer, this installer is designed to package all the mods in the Floating Sandbox: Designer's Studio Discord Server into one simple installer for ease of use. Three basic things to note, this readme won't take too much of your time:

INSTALLATION PATH:

After clicking "Next", you will be shown an installation path that will dictate where the mod files are meant to go. FOR ANYONE WHO HAS INSTALLED FLOATING SANDBOX OUTSIDE OF THE DEFAULT APPDATA FOLDER: You will have to change the installation path to the 'Floating Sandbox' folder where your floatingsandbox.exe application file is. Do NOT set it to "Floating Sandbox\Floating Sandbox" if the parent folder is where floatingsandbox.exe is.

INSTALLING & UNINSTALLING MODS:

After choosing your installation path, you will be shown a list of components, or mods, to install. The top, primary checkboxes dictate whether or not you are going to make any changes to that aspect, be it materials, smoke, or tools. If enabled, you may either install a mod or install the vanilla files - in the event you either don't want a mod or want to uninstall a mod, choose the vanilla files. Unchecking both vanilla & modded files will result in no changes being made.

KNOWN BUGS FOR EXTRA MATERIALS:

- For Gasoline to work properly, please avoid contact with water, and have all your gasoline be at least 2 pixels in both width and height.
- Uranium 235 and Plutonium 239 can crash Floating Sandbox or otherwise make it unstable when there are multiple other explosives onboard a ship. 
- Floating Sandbox 1.21.0 and Extra Materials are known to be temperamental with each other, and will result in GUI glitches (missing buttons or menus), shipbuilder bugs and crashes. Please update to Floating Sandbox 1.21.1 (available in the Designer's Studio Discord) and Extra Materials v4.8.1.
